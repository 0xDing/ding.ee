两年前，你对 Agent 说过一句“我爱吃烤肉”。上个月，你改口告诉它“我开始吃素了”。今天你让它帮忙挑一家聚餐的餐厅，它信心满满地订了一家巴西烤肉。

很多人第一反应是模型变笨了。其实这事怪不到模型头上，毛病出在底下的记忆系统。

眼下市面上做 Agent 记忆，路数大同小异：把说过的话切块、转成向量，一股脑塞进向量库；要用的时候，拿当前的问题算一遍语义相似度，捞出最接近的几段喂给模型。可向量空间里只有远近，没有先后，没有因果，更没有“新说法顶替旧说法”这回事。“爱吃烤肉”和“开始吃素”都被捞了出来，两个点平起平坐，系统分不清哪句还作数，索性挑了离“餐厅”更近的那句。

这顶多算一本带搜索功能的聊天记录归档，根本谈不上记忆。记忆不等于存储，也不等于检索。

Ankole 是我最近在做的开源项目，一套给企业用的 Agent Harness，核心是给数字员工搭一个“公司大脑”。做这个项目这段时间，我大部分精力都花在琢磨这颗大脑该怎么记事上。琢磨得越深，我越笃定一件事：Agent 的长期记忆不该是对话日志的堆砌，而应该是一份世界投影，随着证据不断推演、不断修正。

## 记忆是推出来的，不是存出来的

做后端的同学对事件溯源（Event Sourcing）应该不陌生。这种架构里，数据库只存一笔笔只增不减的事件日志，不存最终状态；账户余额多少、订单走到哪一步，都靠重放日志推出来，推出来的这份视图就叫投影（Projection）。

人的记忆也是这个路数。人脑从来不是录像机，每次回忆，都是拿眼下的线索把过去的碎片重新拼一遍。你对一位老搭档的印象，靠的也是心里那套“这是个什么样的人”的认识，对方每有新举动，你就顺手改一改，哪会去翻每次见面的录像。

Agent 的记忆也该分成两层。底下是证据：谁在什么时候说了什么，读过哪份财报，抓到哪条新闻，只追加，不篡改，随时能翻查。上面是认识，也就是世界投影：从这堆证据里推出来的当前判断，比如这个人现在吃不吃素，那家公司的供应链是不是在转型。新证据进来，旧认识要么修补，要么推翻。

光存聊天记录的系统，把推理的担子全压在了提问那一刻的模型身上。模型那一刻只看得到几段检索出来的碎片，看不出时间线，也理不清因果，不出错才怪。向量检索只管找，记忆是推理出来的。

## 世界不等人开口

市面上聊 Agent 记忆，大多围着人机对话打转：从聊天里摸清用户的偏好、反馈和期望，再靠工程手段把模型能用的上下文撑到接近无界。OpenViking 这些方案在这一块做得都差不多。这当然有用，但远远不够。

LLM 的知识有截止时间，之后世界上发生的事，模型一概不知。有人会说：给它接个搜索引擎不就行了？没那么简单。传统 RAG 有个盲区：不知道哪件事要紧，就不知道该搜什么。就像做原油期货研究，如果不知道美伊爆发了战争，系统根本不可能主动去搜“霍尔木兹海峡”。缺了这层背景，搜索引擎放在手边也是摆设。

刚入行的分析师和干了十年的老手，用的是同一个 Google、同一个 Wind。老手厉害在脑子里有一张活的世界地图：哪家公司和哪家是上下游，哪条航道卡着哪批运油船，央行降个准会顺着什么链路传到哪些板块。这张地图会告诉老手该看什么。

Agent 的记忆得有两条地位平等的输入通道：一条是对话，听人说话，摸清意图和习惯；一条是事件，盯着外部世界，政策变动、财报披露、价格异动、行业重组都算。央行宣布降准，哪怕群里没一个人提，Agent 对相关资产的认识也该跟着更新。有人提要求时，它还得能专门去啃一本书、读一份几十页的研报，把学到的东西消化成记忆。

世界投影不是世界本身，更不是死板的归档日志，它代表的是 Agent 当前这套认知模型：新证据进来，补充、修正或替换旧认识；遗忘、修剪、归纳、合并，让这套模型尽量贴着当下的世界。关系图只是其中一部分，事实和时间上的变化也得一起整理。

## 为什么必须要图，还得是有约束的图

这份投影长什么样？答案是一张图。

向量检索的毛病是把信息切得太碎。“三文鱼”“海胆”“寿司”存进向量库，就是三个悬在高维空间里的孤立点。靠几何距离，没法把它们收拢成“这人偏好日料”；点和点之间也画不了箭头，标不出“吃素”已经顶替了“吃烤肉”。记忆要做的提炼、演化、查冲突，动的全是关系。向量是点，只有图才是网络。

图上，“原油”和“美伊战争”之间有一条直连的边，Agent 研究原油时，相关的事顺着这条边就浮上来了，用不着碰运气去猜搜索词。

图也不能乱连。GraphRAG 从文本里抽实体共现，没有类型约束；普通的图数据库里，“茅台喜欢披萨”是一条完全合法的边，数据库不会拦你。交给大模型随手抽，这种幻觉造出来的荒唐关系会像杂草一样疯长。

在这件事上，Palantir 的本体论（Ontology）给了我很大启发：给关系立规矩。先定好世界里有哪些实体类型，比如公司、指数、事件、人物，再定死哪些类型之间能连什么关系，比如“包含”只能从指数连到公司。有了这层带类型的骨架，大模型抽取时才不会胡乱连线。

纯本体论也有死穴：只能存显式声明的事实，推导出来、还在演化的判断放不进去，精确，但是死的。本体论是骨架，管世界由哪些实体、哪些关系构成；推理出来的记忆是血肉，管这副骨架上正在发生什么、意味着什么。骨架没有血肉是僵死的知识库，血肉没有骨架是无组织的记忆碎片。

我和 Palantir 也有一处根本的分歧：Palantir 的本体是事先自顶向下设计好的，Agent 眼里的世界得自下而上长出来。业务一直在变，今天只需要盯“公司”和“指数”，明天可能就冒出“地缘政策”“供应链卡点”。非要等架构师把所有类型想周全再动手，系统早就僵死了。我的做法是自上而下起步，自下而上演化：先带一小套通用类型跑起来，碰到新概念先打标签；某个概念反复冒出来、证据攒够了，系统再提议把它升格成正式类型，交给人点个头。遗忘、修剪、归纳、合并，让这套本体一点点调整结构。

## 多视角：谁眼中的谁，谁在场，谁能听

同事眼里的你，父母眼里的你，你自己眼里的你，是三套截然不同的认识，各有各的来历，彼此可能矛盾，各自又都说得通。Agent 的记忆也该这样：同一个实体，谁怎么看它，分开记。

做单人助理时，这个问题还不明显。一到企业群聊，事情就复杂了：一个群里有好几个人、好几个数字员工，信息是多对多流动的。系统不光要回答“这个 Agent 记住了这个用户什么”，还得分清群里谁对谁说过什么，哪些认识大家共享，哪些只属于某几个人。

张三在群里吐槽一句“李四这人不靠谱”。要是记忆系统直接存下一句“李四不靠谱”，一个人的看法就成了整个组织的事实，李四在系统里平白被抹黑。每条认识都得绑定两样东西：

- **是事实，还是判断。**“第四季度营收增长 15%”是可以核验的事实；“海外业务进入收获期”是判断。判断要靠时间来验证，到了见分晓的时候得回头算账，看谁判断得准。
- **谁持有这个判断。**“李四不靠谱”不能挂在李四头上，得记在张三名下：这是张三在某个时刻的看法。

我把群聊当作最要紧的场景，是因为企业里最值钱的家当，往往没写进任何文档。哪个部门真正说了算，哪个客户对接时得绕开某位中层，哪个指标看着漂亮其实有水分，这类隐性知识散落在日常沟通里，组织越大越是如此。大厂裁员容易裁到大动脉，裁掉的常常是那个人脑子里一整张没人画下来的关系图，岗位产能倒在其次。

视角还牵出一道更现实的防线：什么话能当着谁说。Agent 是 AI 同事，不是某个人的传话筒，和人类同事守同一套边界：一条知识谁有资格知道，看这条知识自带的可见范围；Agent 开口之前，还要看此刻谁在场。同一条认识，内部人聊的时候可以说，群里拉进来一位外部顾问，就得咽回去。知识归组织，不绑在某个 Agent 身上，哪天某个数字员工下线了，组织的记忆也不会被顺手带走。

## 做梦与遗忘

日志只增不减，系统迟早会被琐碎的细节淹没。在我看来，对人来说，会遗忘本身就是智力的重要一环；要是所有信息永远一样重，真正重要的反而沉了底，Agent 的世界投影也会越来越走样。

为了让记忆自己新陈代谢，我放进了一个叫 Dreaming 的离线批处理，名字取自人睡觉时做梦：白天的经历，夜里拿出来整理。主要做三件事：

- **归纳与演绎。**把零散的观察收拢起来往上推。记忆里有“喜欢吃三文鱼”“喜欢吃金枪鱼”，系统会提炼出一句“这人八成偏好日料”，附上证据，但只当推断，不当事实，往后的证据会坐实、修正或者推翻。演绎是从已有的事实、规则和关系里，推出眼下任务用得上的结论，有长期价值的再写回记忆。
- **理顺矛盾。**用户搬了家，“住在纽约”就该演化成“2019 到 2024 年住在纽约，2024 年起住在西雅图”。两条打架的记录不能并排留着，也不能拿新的直接盖掉旧的。真吃不准的冲突，系统不会悄悄改，整理出来递到人面前，请人拍板。
- **分级遗忘。**遗忘不是物理删除，是降权、冷却，退出默认召回。事件以周计，偏好以月计，事实以年计。两年前那句“爱吃烤肉”早就凉透了，上个月那句“开始吃素”还冒着热气。光凭这套衰减，Agent 就不会再订那家巴西烤肉。

## 宏观架构

把这些拼起来，大致是这样：

```text
对话与群聊 · 新闻、论文、网页与数据 · 外部事件
          │
          ▼  学习：抽取成断言，记下出处、时间、谁的看法、谁能知道
实体 · 事实 · 判断 · 时间线 · 关系（本体）
          │  ▲
          │  └─ Dreaming：归纳、演绎、遗忘、修剪、合并，演化本体
          ▼
召回：全文 + 向量 + 沿关系展开
          │
          ▼  只取提问者有资格知道的，只说在场的人都能听的
        Agent
```

## 尾声

说到底，大模型最擅长的是推理，不是死记硬背。人做深度推理很累，还容易被疲劳、成见和情绪带偏；模型没有心理包袱，前提给足了，就能不知疲倦、前后一致地推下去。Agent 的记忆可以越过人的生物局限：不是记住更多，而是推理更深。
